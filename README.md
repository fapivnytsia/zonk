# ZONK

Кости на 6 костей: бросаешь, откладываешь очковые и решаешь — рисковать дальше или записать очки хода. Побеждает тот, кто первым наберёт цель.

Объёмные кубики, звук, история партии и соперник с двумя характерами — осторожный или азартный, выпадает случайно в начале партии.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | разметка |
| `style.css` | вид |
| `app.js` | логика страницы и анимации |
| `engine/` | правила, ход партии и соперник |
| `fonts/`, `fonts.css` | шрифты Unbounded, Golos Text, JetBrains Mono (лицензия OFL, тексты рядом) |

## Приватность

- Страница не делает внешних запросов: шрифты лежат здесь же.
- В браузере сохраняются только настройки игры (цель и звук) — в `localStorage`.
